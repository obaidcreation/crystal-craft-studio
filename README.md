## ✨ Features

- **Sticky navbar** with logo and WhatsApp button
- **Hero section** with headline, tagline and "Shop Now" call to action
- **4 collections**: Bracelets, Bangles, Necklaces, Earrings
- **6 best sellers** with PKR prices and one-tap WhatsApp ordering
- **FAQ accordion** covering Cash on Delivery, delivery and custom orders
- **Contact form** that prepares a ready-to-send WhatsApp message
- **Auto dark mode**, mobile-first layout and subtle animations
- **SEO-ready**: semantic HTML, meta description and JewelryStore schema
